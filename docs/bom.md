## 器件选型说明

### ESP32-S3 开发板

| 项目 | 要求 | 常见错误 |
|------|------|----------|
| 型号 | ESP32-S3-DevKitC-1 | 买到 ESP32（非 S3）或 ESP32-C3 |
| PSRAM | **必须带 OPI PSRAM**（N16R8 / N8R8） | 无 PSRAM 版 FFT + TFT 刷新会卡顿 |
| Flash | 8 MB 及以上 | — |
| USB | Type-C 或 Micro-USB（按板子） | — |

搜索关键词：`ESP32-S3 N16R8 开发板 PSRAM`、`ESP32-S3 DevKitC-1 N8R8`

### INMP441 麦克风

| 项目 | 要求 | 常见错误 |
|------|------|----------|
| 接口 | **I2S 数字**（SCK / WS / SD） | 误买 **MAX9814 模拟麦**（需 ADC，噪声大） |
| 电压 | 3.3V | 接 5V 可能损坏 |
| 声道 | L/R 引脚接 **GND**（左声道） | 悬空导致声道随机或无声 |
| 引脚 | VDD / GND / SCK / WS / SD / L/R | 模块丝印可能标为 BCK / LRCK / DOUT |

搜索关键词：`INMP441 I2S 麦克风模块`

### ST7789 TFT 屏幕

| 项目 | 要求 | 常见错误 |
|------|------|----------|
| 驱动 | **ST7789** | 买到 ILI9341 / ST7735（库可兼容但 init 不同） |
| 接口 | **4-wire SPI**（丝印 SCL / SDA / RES / DC / CS / BLK） | 买到 8080 16-bit 并口版 |
| 分辨率 | 320×240（横屏，rotation=1） | 尺寸写了 3.2 寸但未标分辨率 |
| 电压 | **3.3V**（VCC） | 误接 5V 烧屏 |
| 尺寸 | 3.2 寸（常见带排针模块） | — |

搜索关键词：`3.2寸 ST7789 SPI 320240`
