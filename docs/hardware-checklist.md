# 硬件联调检查清单

烧录固件前建议按顺序完成以下检查。

## 编译与烧录

- [ ] 确认目标板型：**S3** → `pio run -e esp32-s3-dev`
- [ ] 编译成功，无 error
- [ ] 生成 `firmware.bin`
- [ ] 烧录与监视：`pio run -e esp32-s3-dev -t upload && pio device monitor`

引脚以 [`include/boards/board_s3.h`](../include/boards/board_s3.h) 为准，对照 [wiring.md](wiring.md)。

## 第一阶段：TFT 显示（不接麦克风）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 接 ILI9341 + ESP32，USB 供电 | 上电无异常发热 |
| 2 | 烧录 `esp32-s3-dev` 并打开串口监视器 | 115200 有输出 |
| 3 | 查看启动日志 | `Board: MusicGoGoGo`；TFT 初始化成功 |
| 4 | 查看 TFT | 背光亮；填色或测试图案正常显示 |
| 5 | 检查接线 | VCC 为 3.3V（非 5V）；CS=10, DC=13, RES=14, SDA=11, SCL=12, BLK=3 |

**若 TFT 无显示：**

- 检查 SPI 引脚与 [wiring.md](wiring.md) 对照表
- 确认 VCC 接 3.3V（**勿接 5V**）
- 确认 BLK 接 GPIO 3 且固件已拉高背光
- 尝试对调 SDA/SCL 或检查 CS / DC 是否接反

**若背光不亮：**

- 部分模块 BLK 需接 3.3V 常亮（改接 VCC 或确认 GPIO 3 输出高电平）
- 检查 GND 共地

## 第二阶段：I2S 麦克风采样

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 断电后接 INMP441（VDD/GND/SCK/WS/SD/L/R） | L/R 接 GND |
| 2 | USB 供电，烧录含 I2S 驱动的固件 | 启动无 I2S 初始化错误 |
| 3 | 查看串口 `[audio]` 或 RMS / peak 行 | 安静环境数值接近 0；有底噪属正常 |
| 4 | 对着模块拍手 | peak / RMS 明显跳变 |
| 5 | 对着音箱播放音乐 | 持续波动，非全零 |

**若采样全零或不变：**

- 核对 I2S 引脚：BCK=4, WS=5, SD=6
- 确认 INMP441 L/R 接 **GND**（非悬空）
- 确认 VDD 为 3.3V
- 检查 SD 线是否接到 ESP32 的 DIN（GPIO 6），方向勿反

**若噪声过大：**

- 缩短杜邦线；麦克风远离 USB 线和高频开关电源
- 首版用软件增益调节，勿急于加电位器

## 第三阶段：FFT 频谱分析

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 烧录含 FFT 的固件 | 串口打印频段能量或前 N 个 bin |
| 2 | 安静环境 | 各频段能量较低 |
| 3 | 播放低频音乐（如鼓点） | 低频段（前几个 bin）能量升高 |
| 4 | 播放高频音乐（如镲片） | 高频段能量升高 |
| 5 | 切换音源 | 频段分布随音乐变化 |

**若频谱无响应：**

- 先确认第二阶段 I2S 采样正常
- 检查采样率配置（默认 16 kHz）与 FFT 窗口大小（512）
- 确认 PSRAM 已启用（`BOARD_HAS_PSRAM`）

## 第四阶段：TFT 动态频谱显示

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 烧录完整频谱显示固件 | TFT 底部出现柱状频谱 |
| 2 | 对着音箱播放音乐 | 柱高随节奏跳动 |
| 3 | 观察刷新 | 无明显撕裂或长时间卡顿 |
| 4 | 顶部状态区（若有） | 显示 peak / RMS 或采样率 |
| 5 | 连续运行 5 分钟 | 无重启、无过热 |

**若显示卡顿：**

- 确认开发板带 **OPI PSRAM**（N16R8 / N8R8）
- 降低 FFT 点数或柱状数量（见 `board_s3.h` 中 `FFT_SIZE` / `SPECTRUM_BARS`）
- 减少串口 debug 打印频率

## 完成标志

- [ ] TFT 测试图案正常
- [ ] I2S 拍手有采样响应
- [ ] FFT 频段随音乐变化
- [ ] TFT 柱状频谱流畅刷新

全部通过后，BOM 硬件联调阶段完成，可进入固件功能开发。

## Cardputer ADV 验证（可选）

在未焊接 S3 前，可用 Cardputer ADV 验证麦克风与 VFX。详见 [cardputer-adv.md](cardputer-adv.md)。

### 编译与烧录

- [ ] `pio run -e cardputer-adv -t upload`
- [ ] 串口 115200，启动日志含 `MusicGoGoGo (Cardputer ADV)`

### 内置屏 + 内置麦（默认）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 烧录 `cardputer-adv` | 顶栏显示模式名 + 右上电量 |
| 2 | 默认 VFX（Bars 32） | 柱形随环境声跳动，无斜纹撕裂 |
| 3 | BtnA 短按 | 切换 VFX，无上一模式残影 |
| 4 | BtnA 长按 | 弹出/关闭 mic 调试浮层 |
| 5 | 对着麦克风说话 | 调试浮层中 `raw[...]` 范围增大 |
| 6 | `[` / `]` | 增益变化，柱高响应改变 |

### 外接 EXT ST7789（`CARDPUTER_USE_BUILTIN_LCD 0`）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 按 [wiring.md](wiring.md) 接 EXT 14P → 2.4" 屏 | 8 线接齐 |
| 2 | 烧录并观察 | 320×240 横屏频谱正常 |
| 3 | 画面偏移 | 调整 `TFT_Y_OFFSET`（0 或 80） |

### Cardputer 完成标志

- [ ] 7 种 VFX 可切换且无严重撕裂
- [ ] 麦克风对声音有响应（调试浮层或串口 `[bands]`）
- [ ] 电量显示合理
- [ ] 连续运行 5 分钟无重启
